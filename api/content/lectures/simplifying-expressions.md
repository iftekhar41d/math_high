# Simplifying Expressions

To **simplify** an expression is to write it in the shortest equivalent form,
mainly by **collecting like terms**.

## Collecting like terms

Add or subtract the coefficients of terms with the same pronumeral part; leave
unlike terms as they are.
$$4x + 3x = 7x, \qquad 9a - 2a = 7a, \qquad 5y + 2 - y = 4y + 2.$$

Keep the sign in front of each term with it:
$$3m + 7 - 5m - 2 = (3m - 5m) + (7 - 2) = -2m + 5.$$

## Multiplying terms

Multiply the numbers, then the pronumerals:
$$4 \times 3a = 12a, \qquad 2a \times 5b = 10ab, \qquad x \times x = x^2.$$

## Dividing terms

Write the division as a fraction and cancel common factors:
$$\frac{12x}{4} = 3x, \qquad \frac{10ab}{2a} = 5b.$$

::: example Simplify fully
$$6p + 4 - 2p + 3p - 9.$$
Like terms in $p$: $6p - 2p + 3p = 7p$. Constants: $4 - 9 = -5$. Result:
$7p - 5$.
:::

::: callout $x$ and $x^2$ are not like terms
$x + x = 2x$, but $x \times x = x^2$. You can only combine terms whose pronumeral
parts match *exactly*, powers included.
:::
