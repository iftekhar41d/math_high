# Types of Angles

An **angle** measures an amount of turn between two rays that share an endpoint
(the **vertex**). We measure angles in **degrees** ($^\circ$); a full turn is
$360^\circ$.

## Classifying by size

| Name | Size |
|:--|:--|
| Acute | between $0^\circ$ and $90^\circ$ |
| Right | exactly $90^\circ$ |
| Obtuse | between $90^\circ$ and $180^\circ$ |
| Straight | exactly $180^\circ$ |
| Reflex | between $180^\circ$ and $360^\circ$ |

A right angle is often marked with a small square instead of an arc.

## Naming angles

An angle can be named by three points, with the **vertex in the middle**:
$\angle ABC$ has its vertex at $B$. When there is no ambiguity, a single letter
$\angle B$ is enough.

::: example Classify and name
Two roads meet at point $P$, turning through $130^\circ$. This is an **obtuse**
angle, written $\angle P = 130^\circ$.
:::

::: callout Estimate before you measure
Decide which class an angle is in first. If your protractor reading is $40^\circ$
but the angle is clearly obtuse, you have read the wrong scale — it should be
$140^\circ$.
:::
