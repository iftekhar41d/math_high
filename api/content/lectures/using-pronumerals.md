# Using Pronumerals

A **pronumeral** is a letter that stands for a number. It lets us write a rule
that works for *every* value, not just one.

If a pen costs $\$3$, then $n$ pens cost $3n$ dollars. Here $3n$ means
$3 \times n$ — in algebra we drop the multiplication sign.

## Algebra shorthand

| Words | Algebra |
|:--|:--|
| $5$ times $x$ | $5x$ |
| $x$ divided by $2$ | $\dfrac{x}{2}$ |
| $x$ plus $7$ | $x + 7$ |
| $3$ less than $x$ | $x - 3$ |
| $x$ multiplied by itself | $x^2$ |

The number in front of a pronumeral is its **coefficient**; in $5x$ the
coefficient is $5$. A term with no pronumeral, like $7$, is a **constant**.

::: example Writing an expression
A taxi charges a $\$4$ flagfall plus $\$2$ per kilometre. The cost of a
$k$-kilometre trip is
$$4 + 2k \text{ dollars.}$$
:::

::: callout Order matters for subtraction and division
"$3$ less than $x$" is $x - 3$, **not** $3 - x$. "$x$ divided by $2$" is
$\dfrac{x}{2}$, not $\dfrac{2}{x}$. Read carefully which quantity comes first.
:::

## Like terms

Terms are **like terms** if they have exactly the same pronumeral part: $2x$ and
$5x$ are like terms; $2x$ and $2x^2$ are not; $3xy$ and $7yx$ are (order of
letters does not matter).
