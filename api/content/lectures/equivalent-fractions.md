# Equivalent Fractions

A fraction $\dfrac{a}{b}$ describes $a$ parts out of $b$ equal parts. Different
fractions can name the **same amount** — these are **equivalent fractions**.

$$\frac{1}{2} = \frac{2}{4} = \frac{3}{6} = \frac{50}{100}.$$

## Making equivalent fractions

Multiplying **or** dividing the numerator and denominator by the same non-zero
number does not change the value:
$$\frac{2}{3} = \frac{2 \times 4}{3 \times 4} = \frac{8}{12}.$$

This works because you are multiplying by $\dfrac{4}{4} = 1$.

## Simplest form

A fraction is in **simplest form** when the numerator and denominator share no
common factor except $1$. Divide both by their highest common factor:
$$\frac{18}{24} = \frac{18 \div 6}{24 \div 6} = \frac{3}{4}.$$

::: example Comparing two fractions
Which is larger, $\dfrac{3}{4}$ or $\dfrac{5}{6}$?

Rewrite both with denominator $12$: $\dfrac{3}{4} = \dfrac{9}{12}$ and
$\dfrac{5}{6} = \dfrac{10}{12}$. Since $10 > 9$, $\dfrac{5}{6}$ is larger.
:::

::: callout Common denominator
To compare or combine fractions, first rewrite them over a shared denominator —
the lowest common multiple of the denominators is the tidiest choice.
:::
