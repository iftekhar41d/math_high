# Adding and Subtracting Fractions

You can only add or subtract fractions that are cut into the **same size
pieces** — that is, fractions with a **common denominator**.

## Same denominator

Add or subtract the numerators and keep the denominator:
$$\frac{2}{7} + \frac{3}{7} = \frac{5}{7}, \qquad \frac{5}{9} - \frac{2}{9} = \frac{3}{9} = \frac{1}{3}.$$

## Different denominators

1. Find a common denominator (the lowest common multiple of the denominators).
2. Rewrite each fraction as an equivalent fraction over it.
3. Add or subtract the numerators.
4. Simplify.

::: example Unlike denominators
$$\frac{1}{4} + \frac{2}{3}.$$
The lowest common multiple of $4$ and $3$ is $12$:
$$\frac{1}{4} = \frac{3}{12}, \qquad \frac{2}{3} = \frac{8}{12}.$$
So $\dfrac{3}{12} + \dfrac{8}{12} = \dfrac{11}{12}$.
:::

## Mixed numbers

Convert mixed numbers to improper fractions first:
$$2\tfrac{1}{2} - 1\tfrac{1}{3} = \frac{5}{2} - \frac{4}{3} = \frac{15}{6} - \frac{8}{6} = \frac{7}{6} = 1\tfrac{1}{6}.$$

::: callout Check your answer is reasonable
$\tfrac{1}{4} + \tfrac{2}{3}$ should be a bit less than $1$, since $\tfrac{2}{3}$
is less than $1$ and $\tfrac14$ is small. $\tfrac{11}{12}$ fits — a quick sanity
check catches arithmetic slips.
:::
