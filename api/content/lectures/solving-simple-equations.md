# Solving Simple Equations

An **equation** says two expressions are equal. To **solve** it is to find the
value of the pronumeral that makes it true.

The key idea: **whatever you do to one side, do to the other**. The equation
stays balanced, like a set of scales.

## One step

$$x + 7 = 12 \ \xrightarrow{\,-7\,}\ x = 5.$$
$$3x = 21 \ \xrightarrow{\,\div 3\,}\ x = 7.$$
$$\frac{x}{4} = 2 \ \xrightarrow{\,\times 4\,}\ x = 8.$$

Undo the operation on the pronumeral with its **inverse**: subtraction undoes
addition, division undoes multiplication.

## Two steps

Undo addition/subtraction first, then multiplication/division.

::: example A two-step solve
$$2x + 5 = 17.$$
Subtract $5$: $2x = 12$. Divide by $2$: $x = 6$.
:::

## Checking

Substitute your answer back into the **original** equation. For $x = 6$ above:
$2(6) + 5 = 17$ ✓.

::: callout Do the same thing to *every* term
When you divide, divide the whole of each side. From $2x + 4 = 10$, dividing by
$2$ gives $x + 2 = 5$, not $x + 4 = 5$.
:::
