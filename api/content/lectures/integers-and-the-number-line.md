# Integers and the Number Line

**Integers** are the whole numbers together with their negatives and zero:
$$\ldots, -3, -2, -1, 0, 1, 2, 3, \ldots$$

They stretch out forever in both directions. We picture them as evenly spaced
points on a **number line**, with $0$ in the middle, positive integers to the
right and negative integers to the left.

## Comparing integers

On the number line, a number is **greater** than another when it sits further to
the **right**. So $2 > -5$, even though $5$ is "bigger" than $2$ — the sign
matters. Moving left makes a number smaller; moving right makes it larger.

::: example Ordering a list
Put $-3,\ 4,\ 0,\ -1$ in ascending order.

Reading the number line left to right: $-3$ is furthest left, then $-1$, then
$0$, then $4$. So the order is $-3, -1, 0, 4$.
:::

## Opposites and absolute value

Every integer has an **opposite** the same distance from $0$ on the other side:
the opposite of $7$ is $-7$, and the opposite of $-7$ is $7$.

The **absolute value** $|n|$ is that distance from zero, ignoring direction, so
$|{-7}| = 7$ and $|7| = 7$.

::: callout Sign vs. size
$-100$ is *less than* $-1$: it is further left. Bigger digits do not mean a
bigger number once negatives are involved — always think about position on the
line.
:::

## Where integers show up

Temperatures below zero, floors below ground level, money owed, and points lost
in a game are all everyday negatives. The number line is the model that makes
arithmetic with them consistent.
