# Substitution

**Substitution** means replacing each pronumeral with a given number and then
evaluating, following the order of operations.

::: example One pronumeral
Evaluate $3x + 4$ when $x = 5$.
$$3(5) + 4 = 15 + 4 = 19.$$
:::

Always write the number in brackets where the pronumeral was — it keeps
multiplication clear and stops sign errors.

## More than one pronumeral

Evaluate $2a - b$ when $a = 7$ and $b = 10$:
$$2(7) - 10 = 14 - 10 = 4.$$

## Negatives and powers

Take extra care with negative values and indices:
$$x^2 \text{ when } x = -3 \ \Rightarrow\ (-3)^2 = 9,$$
$$5 - 2y \text{ when } y = -4 \ \Rightarrow\ 5 - 2(-4) = 5 + 8 = 13.$$

::: callout Brackets save you
$(-3)^2 = 9$ but $-3^2 = -9$: without brackets the power applies only to the
$3$. When you substitute a negative number, bracket it every time.
:::

## Using formulas

Substitution is how formulas do their job. The perimeter of a rectangle is
$P = 2(l + w)$; with $l = 8$ and $w = 3$,
$$P = 2(8 + 3) = 2(11) = 22.$$
