# Adding and Subtracting Integers

Think of addition as **movement along the number line**. Starting at the first
number, a positive amount moves you **right** and a negative amount moves you
**left**.

- $3 + 4$: start at $3$, move $4$ right $\to 7$.
- $3 + (-4)$: start at $3$, move $4$ left $\to -1$.
- $-3 + (-4)$: start at $-3$, move $4$ left $\to -7$.

## Adding numbers with the same sign

Add the absolute values and keep the shared sign:
$$-6 + (-5) = -(6 + 5) = -11.$$

## Adding numbers with different signs

Subtract the smaller absolute value from the larger, and keep the sign of the
number that was further from zero:
$$-8 + 3 = -(8 - 3) = -5, \qquad 8 + (-3) = +(8 - 3) = 5.$$

## Subtraction is adding the opposite

To subtract an integer, add its opposite:
$$a - b = a + (-b).$$

::: example Subtracting a negative
$$5 - (-2) = 5 + 2 = 7.$$
Taking away a debt of $2$ leaves you $2$ better off — subtracting a negative
moves you **right**.
:::

::: callout Two signs together
Rewrite $+\,(-n)$ as $-\,n$ and $-\,(-n)$ as $+\,n$ before you compute. A tidy
first step prevents most sign mistakes.
:::
