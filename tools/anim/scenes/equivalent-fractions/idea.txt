Topic: Equivalent Fractions (Year 7 Mathematics, NSW).

Teach that different fractions can name the same amount, and how to make
equivalent fractions by multiplying numerator and denominator by the same number.

Sequence (aim for about 30 seconds):
1. Title "Equivalent Fractions".
2. Show a horizontal bar split into 2 equal parts with 1 part shaded; label 1/2.
3. Split every part in half so the bar now has 4 parts with 2 shaded; label 2/4.
   The shaded region visibly does not change.
4. Split again into 6 parts with 3 shaded; label 3/6. Show "1/2 = 2/4 = 3/6".
5. Show the rule with equations: 1/2 = (1x3)/(2x3) = 3/6, and note that
   multiplying by 3/3 is multiplying by 1, so the value is unchanged.
6. End on "Same amount, different names" and a 1 second hold.

Keep it mathematically correct and age-appropriate. Use only the palette colours
(Background #F9F7F7, Accent #DBE2EF, Primary #3F72AF, Dark/Text #112D4E).
